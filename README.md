# OpenDash extras: HD art for Mega Man Legends 2

HD art made by Herbert Costa for [OpenDash](https://github.com/mateuspina69/opendash), the Mega Man Legends 2 engine
reimplementation. It lives here, apart from OpenDash, because it redraws the game's own art; OpenDash runs without it
(the pixel art stays) and is better with it.

**No original game files are here.** You still need your own copy of the game, as OpenDash asks.

| Folder | What |
| --- | --- |
| `assets/ui/title/` | the title menu's words in each language (new game, continue, tutorial, options, extras), in the menu's yellow style |
| `assets/ui/credits/` | the staff roll's pages in HD |
| `assets/ui/flags/` | the language flags of Options > Language |
| `assets/ui/icons/` | the 14 item icons of the menus, redrawn as vector art |
| `assets/ui/language.svg`, `options_junction.svg`, `dualshock.svg` | the globe of the language row, the options page's frame corner, the controller of the key configuration |
| `assets/ui/hand_fill.png`, `hand_edge.png` | the selection hand in HD (every pointing-hand cursor), painted in the text colours |

## Install

Download the zip from the Releases page, unzip it inside your OpenDash folder (the one with `opendash.exe`) and run
`install.bat`. Or copy the `assets` folder next to `opendash.exe` yourself, merging it with the one already there.

## Coming later

There is more HD material made for this version: the Extras albums (official art, books and manuals), the HD logos,
the HD mission banners and the menu backdrop. It is not here yet because I'm still working out the best way to make
it available. It will be announced here.

# OpenDash extras: artes em HD para Mega Man Legends 2

Artes em HD feitas por Herbert Costa para o [OpenDash](https://github.com/mateuspina69/opendash). Ficam aqui, separadas
do OpenDash, porque redesenham a arte do próprio jogo; o OpenDash funciona sem elas (fica a arte em pixel) e fica mais
bonito com elas. **Nenhum arquivo original do jogo está aqui.**

**Instalar:** baixe o zip na página Releases, descompacte dentro da pasta do OpenDash (a do `opendash.exe`) e rode o
`install.bat`. Ou copie a pasta `assets` para a pasta do `opendash.exe`, juntando com a que já existe.

**Em breve:** há mais material em HD feito para esta versão (os álbuns dos Extras com arte oficial, livros e manuais,
os logos em HD, as faixas de missão em HD e o fundo dos menus). Ainda não está aqui porque estou pensando na melhor
forma de disponibilizar; vou avisar aqui quando estiver.
